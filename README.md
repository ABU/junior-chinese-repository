# 國文練習室：國二上複習

## 本機閱讀

1. 解壓縮下載的 ZIP。
2. 用 Chrome、Edge、Firefox 或 Safari 開啟 `index.html`，不需安裝工具、不需啟動伺服器。
3. 點「題庫檢閱」，可一次查看72題、答案與解析，也可按單元和難度篩選。
4. 核心內容離線可用；外部影片和來源需連網。iPhone「檔案」的預覽不一定執行互動網頁，建議以電腦瀏覽器檢閱；若手機只有靜態預覽，先閱讀隨附的 `difficulty-review.md`。
